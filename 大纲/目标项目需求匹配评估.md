# 目标项目需求匹配评估

## 结论

`目标项目.md` 的方向基本能覆盖图片中的 CFO 需求，但目前还只是“能支撑”的产品架构，不是“已经完整定义”的功能方案。

它已经具备三类关键基础：

- 产品定位明确：AI 个人财务 CFO，回答“该怎么花”和“选择会带来什么后果”。
- 核心引擎方向正确：现金流预测、偿债策略对比、目标达成路径规划、场景影响量化。
- 数据底座合理：资产账户、负债记录、收支流水、模拟场景、计算历史。

但图片中的需求还需要补充为更明确的业务模块、输入字段、计算指标和页面功能。尤其是预算管理、应急资金、风险管理、投资制度、财务复盘，目前在文档中只是间接覆盖。

## 逐项匹配

| CFO 视角 | 图片中的个人动作 | 当前文档覆盖情况 | 判断 |
|---|---|---|---|
| 现金流管理 | 记录每月收入、固定支出、可变支出、结余率 | 文档已有“收支流水”“现金流预测”“数据管理”，可以支撑收入、支出和结余分析 | 基本覆盖 |
| 预算管理 | 给消费、学习、旅行、投资设月度预算 | 文档没有明确“预算”模型和预算执行追踪，只能通过收支分类间接实现 | 部分覆盖 |
| 应急资金 | 留 3-6 个月生活费 | 文档有“目标达成路径规划”和“场景模拟”，但没有明确应急金指标和规则 | 部分覆盖 |
| 资产负债表 | 每月统计现金、理财、基金、股票、房产、贷款、信用卡 | 文档有“资产账户”和“负债记录”，资产负债表方向成立 | 基本覆盖 |
| 负债管理 | 区分低息负债和高息负债，优先还高息债 | 文档已有“偿债策略对比”，但需要明确利率、还款顺序和风险提示 | 基本覆盖 |
| 风险管理 | 配保险、控制单一资产比例、避免杠杆 | 文档有“场景影响量化”，但没有保险、集中度、杠杆率等风险指标 | 部分覆盖 |
| 投资制度 | 写下买入规则、仓位上限、再平衡规则 | 文档有外部市场数据可选，但没有投资纪律、仓位限制、再平衡规则模块 | 明显不足 |
| 财务复盘 | 每月/每季度复盘预算、收益、风险、目标进度 | 文档有“计算历史”和“模拟场景记录”，但没有复盘报表和周期性总结设计 | 部分覆盖 |

## 主要缺口

### 1. 缺少预算实体

当前数据模型里有收支流水，但没有预算表。若要满足预算管理，需要增加：

- 预算周期：月度、季度、年度。
- 预算分类：消费、学习、旅行、投资等。
- 预算金额。
- 实际支出。
- 剩余额度。
- 超支提醒。

### 2. 缺少财务健康指标

图片里的 CFO 视角不是单纯记账，而是持续判断财务状态。建议加入指标：

- 结余率。
- 储蓄率。
- 应急金覆盖月数。
- 负债收入比。
- 高息负债占比。
- 净资产变化。
- 单一资产占比。
- 杠杆率。
- 目标完成率。

### 3. 缺少规则系统

投资制度和风险管理都需要“规则”，而不是只靠一次性计算。建议增加：

- 买入规则。
- 卖出规则。
- 仓位上限。
- 再平衡规则。
- 高息负债优先级规则。
- 单一资产集中度上限。
- 风险预警规则。

### 4. 缺少复盘工作流

文档已有计算历史，但复盘需要面向用户的流程：

- 自动生成月度复盘。
- 对比预算和实际支出。
- 对比净资产变化。
- 对比目标进度。
- 总结本月风险变化。
- 给出下月行动建议。

## 建议补充到目标项目的模块

可以在 `目标项目.md` 的“核心模块”中补充以下模块：

| 模块 | 职责 | 技术要点 |
|---|---|---|
| 预算管理 | 设置分类预算，追踪预算执行和超支情况 | 预算表、分类聚合、超支提醒 |
| 财务健康评分 | 汇总现金流、负债、资产、风险、目标进度 | 指标计算、阈值规则、趋势对比 |
| 应急金管理 | 计算当前应急金覆盖月数，规划补足路径 | 月均必要支出、覆盖月数、目标缺口 |
| 风险规则引擎 | 检查杠杆、集中度、高息负债、保险缺口 | 规则配置、预警等级、行动建议 |
| 投资纪律 | 管理买入规则、仓位上限和再平衡规则 | 规则记录、持仓占比、再平衡提示 |
| 周期复盘 | 生成月度/季度财务复盘 | 报表生成、同比/环比、目标进度 |

## 最终判断

如果按图片里的 8 件事作为目标，当前 `目标项目.md` 可以作为第一版项目方向，但还不能说已经完全满足需求。

更准确的判断是：

- 现金流、资产负债、负债管理：已经有比较清晰的技术支撑。
- 预算、应急资金、风险管理、财务复盘：有基础，但需要补充明确模块。
- 投资制度：目前缺口最大，需要新增规则和纪律管理。

建议下一步直接把这些缺口补入 `目标项目.md`，让目标项目从“AI 财务问答 + 计算引擎”升级为“个人 CFO 管理系统”。
