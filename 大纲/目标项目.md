### 技术栈

|层|技术|说明|
|---|---|---|
|框架|Next.js 15|全栈：前端 + API Routes|
|前端|React + TailwindCSS|对话界面 + 财务面板|
|计算引擎|纯 TS 函数|确定性财务计算，不用 LLM 算数|
|LLM|DeepSeek API|仅做意图解析和语言组织|
|存储|SQLite（本地）|零部署，数据全在本地|
|ORM|Drizzle|轻量 TS ORM，类型安全|
|数据导入|CSV 解析|银行流水/支付宝账单导入|

### 核心模块

|模块|职责|技术要点|
|---|---|---|
|**意图解析**|自然语言 → 结构化财务查询|LLM 提取参数（金额/时间/目标），输出 JSON|
|**计算引擎**|所有财务数学的确定性执行|decimal.js 保精度，每步可溯源|
|**场景模拟**|What-if 分析|参数化计算：输入变化 → 输出对比|
|**数据管理**|收支/负债/资产 CRUD|自动分类 + 手动修正|
|**验证层**|计算结果可审计|保存每次计算的输入参数 + 公式 + 输出|

### 关键设计原则（来自 Hiro）

> **LLM 只做语言翻译，核心逻辑交给确定性代码**

code复制

```
用户："我两年内能攒够 50 万吗？"
 ↓
LLM 解析意图 → { 目标: 500000, 期限: 2年, 类型: "储蓄目标" }
 ↓
确定性引擎计算 → 当前储蓄率 × 24个月 + 复利 = 52.3万 ✓
 ↓
LLM 组织回复 → "按当前储蓄率，两年后预计 52.3 万，达标。
 点击查看计算过程 →"
```

每一步可验证，不是 AI 瞎编。
