# 第 2 课：开发环境准备

## 本课目标

从这一课开始，我们要真正把项目跑起来。

对于编程小白来说，开发环境准备可能会有点陌生，因为它涉及几个以前不常接触的工具：

- Node.js
- npm
- package.json
- VS Code
- 终端
- Next.js 项目

这节课不要求你理解所有底层原理，只要求你完成一件事：

> 在自己的电脑上创建并启动第一个 Next.js 项目。

学完本课后，你应该能够：

- 知道 Node.js 是用来运行 JavaScript / TypeScript 项目的工具。
- 知道 npm 是用来安装和管理项目依赖的工具。
- 知道 `package.json` 是项目说明书。
- 能用 VS Code 打开项目文件夹。
- 能在终端里运行基础命令。
- 能创建一个 Next.js 项目并在浏览器打开首页。

## 一、为什么要准备开发环境

我们最终要做的是一个本地版 **AI 个人财务 CFO**。

它不是一个单独的 HTML 页面，而是一个完整的 Web 应用：

- 前端页面用 React 编写。
- 项目框架使用 Next.js。
- 业务逻辑使用 TypeScript。
- 后面还会连接 SQLite 数据库。
- 后端 API 也会写在同一个 Next.js 项目里。

所以在正式写功能前，电脑上必须先具备运行这个项目的能力。

你可以把开发环境理解成：

> 写代码、安装工具、启动项目、查看效果所需的一整套基础设施。

## 二、需要安装哪些工具

本课程至少需要安装三个工具。

### 1. Node.js

Node.js 的作用是让电脑可以直接运行 JavaScript。

以前 JavaScript 主要运行在浏览器里，比如 Chrome、Safari、Edge。

但现代 Web 项目需要在本地电脑上完成很多事情：

- 创建项目。
- 编译 TypeScript。
- 启动开发服务器。
- 安装第三方依赖。
- 运行测试。

这些都需要 Node.js。

本课程建议安装 **Node.js LTS 版本**。

LTS 的意思是 Long Term Support，也就是长期维护版本。对于初学者来说，不需要追最新版本，使用 LTS 更稳定。

安装地址：

```txt
https://nodejs.org/
```

进入官网后，选择 LTS 版本下载安装即可。

### 2. VS Code

VS Code 是代码编辑器。

你可以把它理解成专门写代码的高级文本编辑器。

它可以帮助我们：

- 查看项目文件。
- 编辑代码。
- 高亮 TypeScript、React、CSS。
- 提示错误。
- 在内置终端中运行命令。

安装地址：

```txt
https://code.visualstudio.com/
```

### 3. 浏览器

推荐使用 Chrome 或 Edge。

后续开发过程中，我们会频繁在浏览器里查看页面效果，并使用开发者工具检查错误。

本课暂时只需要能打开本地地址即可。

## 三、检查 Node.js 是否安装成功

安装 Node.js 后，打开终端。

不同系统打开终端的方式不同：

- macOS：打开“终端”应用，或在 VS Code 里打开 Terminal。
- Windows：打开 PowerShell，或在 VS Code 里打开 Terminal。

在终端中输入：

```bash
node -v
```

如果看到类似下面的输出，说明 Node.js 安装成功：

```txt
v20.11.0
```

版本号不需要和示例完全一样，只要能输出版本号即可。

然后继续输入：

```bash
npm -v
```

如果看到类似下面的输出，说明 npm 也可以正常使用：

```txt
10.2.4
```

### 如果命令无法识别怎么办

如果终端提示 `node` 或 `npm` 无法识别，通常说明：

- Node.js 没有安装成功。
- 安装后没有重新打开终端。
- 系统环境变量没有刷新。

可以先尝试：

1. 关闭终端。
2. 重新打开终端。
3. 再次运行 `node -v` 和 `npm -v`。

如果仍然不行，重新安装 Node.js LTS 版本。

## 四、理解 npm、package.json 和依赖包

创建项目之前，我们先理解三个非常重要的概念。

### 1. npm 是什么

npm 是 Node.js 自带的包管理工具。

你可以把它理解成：

> JavaScript 世界的应用商店和项目管家。

它可以帮我们：

- 下载别人写好的工具包。
- 记录项目需要哪些依赖。
- 运行项目里的脚本命令。

比如后面我们会用到：

```bash
npm run dev
```

这条命令的意思是：

> 运行当前项目里名叫 `dev` 的脚本，启动开发服务器。

### 2. 依赖包是什么

依赖包就是项目需要使用的第三方代码。

例如：

- `next`：提供 Next.js 框架能力。
- `react`：提供组件化界面能力。
- `react-dom`：把 React 组件渲染到浏览器页面里。

我们不需要从零写出整个 Web 框架，而是站在这些成熟工具的基础上开发自己的业务功能。

### 3. package.json 是什么

`package.json` 是一个项目的说明书。

它通常记录：

- 项目名称。
- 项目版本。
- 可以运行哪些命令。
- 项目依赖哪些包。
- 开发时依赖哪些工具。

一个简化版 `package.json` 可能长这样：

```json
{
  "name": "ai-finance-cfo",
  "version": "0.1.0",
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start"
  },
  "dependencies": {
    "next": "15.0.0",
    "react": "19.0.0",
    "react-dom": "19.0.0"
  }
}
```

现在不需要记住每个字段，只要先知道：

> 以后看到 `package.json`，就知道它是项目的配置和依赖说明文件。

## 五、认识终端和常用命令

终端是用文字命令操作电脑的工具。

刚开始可能不习惯，但写代码时它非常常用。

本课程前期只需要掌握几个基础命令。

### 1. 查看当前所在目录

macOS / Linux：

```bash
pwd
```

Windows PowerShell：

```powershell
pwd
```

### 2. 查看当前目录下有哪些文件

macOS / Linux：

```bash
ls
```

Windows PowerShell：

```powershell
dir
```

### 3. 进入某个文件夹

```bash
cd 文件夹名称
```

例如：

```bash
cd ai-finance-cfo
```

### 4. 返回上一级目录

```bash
cd ..
```

### 5. 停止正在运行的命令

如果终端正在运行开发服务器，想停止它，可以按：

```txt
Ctrl + C
```

终端可能会询问是否终止，输入 `y` 后按回车即可。

## 六、创建项目目录

先选择一个专门放代码项目的位置。

例如你可以在桌面或文档目录下创建一个文件夹：

```txt
projects
```

然后在终端中进入这个目录。

macOS 示例：

```bash
cd ~/Desktop/projects
```

Windows 示例：

```powershell
cd Desktop\projects
```

如果你已经有固定的学习目录，也可以直接使用自己的目录。

本课程的最终项目建议命名为：

```txt
ai-finance-cfo
```

## 七、创建第一个 Next.js 项目

在你准备放项目的目录里运行：

```bash
npx create-next-app@latest ai-finance-cfo
```

`npx` 可以临时运行 npm 上的工具。

这条命令的意思是：

> 使用官方脚手架创建一个名为 `ai-finance-cfo` 的 Next.js 项目。

运行后，终端会询问一些选项。

建议选择：

```txt
Would you like to use TypeScript? Yes
Would you like to use ESLint? Yes
Would you like to use Tailwind CSS? Yes
Would you like your code inside a `src/` directory? No
Would you like to use App Router? Yes
Would you like to use Turbopack? Yes
Would you like to customize the import alias? No
```

如果某些选项文字略有不同，不要紧，重点是：

- 使用 TypeScript。
- 使用 Tailwind CSS。
- 使用 App Router。
- 项目目录名称为 `ai-finance-cfo`。

等待命令执行完成后，你会得到一个新文件夹：

```txt
ai-finance-cfo/
```

## 八、用 VS Code 打开项目

进入项目目录：

```bash
cd ai-finance-cfo
```

如果你的电脑已经安装了 VS Code 的 `code` 命令，可以运行：

```bash
code .
```

这会用 VS Code 打开当前项目。

如果 `code .` 无法使用，也可以手动打开：

1. 打开 VS Code。
2. 点击 File。
3. 点击 Open Folder。
4. 选择 `ai-finance-cfo` 文件夹。

打开后，你应该能看到类似下面的项目结构：

```txt
ai-finance-cfo/
├── app/
│   ├── favicon.ico
│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx
├── public/
├── package.json
├── next.config.ts
├── tsconfig.json
└── ...
```

其中本课最重要的是两个位置：

- `package.json`：项目命令和依赖。
- `app/page.tsx`：首页页面代码。

## 九、启动本地开发服务器

确保终端位于项目目录 `ai-finance-cfo` 内。

然后运行：

```bash
npm run dev
```

如果成功，你会看到类似输出：

```txt
Local: http://localhost:3000
```

这表示开发服务器已经启动。

打开浏览器，访问：

```txt
http://localhost:3000
```

如果浏览器中出现 Next.js 默认首页，说明项目已经成功运行。

### 什么是 localhost

`localhost` 表示“当前这台电脑”。

所以：

```txt
http://localhost:3000
```

可以理解为：

> 在浏览器里访问当前电脑上 3000 端口运行的 Web 项目。

后续我们开发项目时，大部分时间都会通过这个地址查看效果。

## 十、第一次修改页面

现在我们做一个非常小的修改，确认代码和页面是连通的。

打开：

```txt
app/page.tsx
```

把页面内容先改成一个简单版本：

```tsx
export default function Home() {
  return (
    <main className="min-h-screen p-8">
      <h1 className="text-3xl font-bold">AI 个人财务 CFO</h1>
      <p className="mt-4 text-gray-600">
        这是我的第一个 Next.js 页面。
      </p>
    </main>
  );
}
```

保存文件后，回到浏览器。

通常页面会自动刷新。如果没有刷新，可以手动刷新浏览器。

你应该看到页面标题变成：

```txt
AI 个人财务 CFO
```

这一步很重要，因为它说明：

- VS Code 可以编辑项目代码。
- Next.js 开发服务器正在运行。
- 浏览器可以显示你的修改结果。

## 十一、常见问题

### 1. npm run dev 报错：找不到 package.json

这通常说明你没有进入项目目录。

先运行：

```bash
ls
```

或 Windows PowerShell：

```powershell
dir
```

看当前目录里有没有 `package.json`。

如果没有，进入项目目录：

```bash
cd ai-finance-cfo
```

然后重新运行：

```bash
npm run dev
```

### 2. 端口 3000 被占用

如果终端提示 3000 端口已经被占用，Next.js 可能会询问是否使用其他端口。

可以输入：

```txt
y
```

然后它可能会使用：

```txt
http://localhost:3001
```

这时就打开新的地址。

### 3. 页面没有自动更新

可以尝试：

1. 确认文件已经保存。
2. 手动刷新浏览器。
3. 查看终端是否有报错。
4. 停止服务器后重新运行 `npm run dev`。

### 4. 终端里出现红色错误

不要慌。

编程时看到错误是正常现象。

先看错误信息里有没有文件名，比如：

```txt
app/page.tsx
```

如果有，说明问题大概率出在这个文件。

对于初学者来说，最常见的问题是：

- 少了括号。
- 少了引号。
- 标签没有闭合。
- 复制代码时漏了一行。
