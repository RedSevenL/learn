# 第 24 课：债务偿还策略

## 本课目标

第 23 课研究的是：

```txt
当前金额和每月储蓄
  ↓
未来能否达到储蓄目标
```

这一课换一个方向，研究：

```txt
当前债务和每月还款预算
  ↓
需要多久才能还清
一共要支付多少利息
不同还款顺序有什么差异
```

项目中的 `liabilities` 表已经能够保存：

```txt
初始本金 principal
剩余本金 remainingPrincipal
年利率 annualRate
最低还款额 minimumPayment
```

当用户同时有多笔债务时，除了按时支付最低还款，还需要决定：

> 每个月额外能拿出的还款金额，应该优先还哪一笔？

本课会实现两种常见策略：

```txt
债务雪球法：优先偿还余额最小的债务
债务雪崩法：优先偿还利率最高的债务
```

并在同一组债务、同一份月还款预算下比较：

- 优先顺序。
- 每笔债务的还清月份。
- 全部还清所需月份。
- 总支付金额。
- 总利息成本。
- 雪崩法节省的利息。

学完后，你应该能够：

- 解释最低还款和额外还款的区别。
- 解释雪球法和雪崩法的排序规则。
- 把年利率转换为月利率。
- 按月模拟计息和还款。
- 防止还款额超过当月剩余债务。
- 在债务还清后滚动释放还款预算。
- 输出还清时间和预计利息。
- 在相同预算下公平比较两种策略。
- 使用 `Decimal` 避免金额浮点误差。
- 为排序、还款结果和异常输入编写测试。

## 二、先认识项目中的负债字段

当前 `liabilities` 表包含：

```ts
principal
remainingPrincipal
annualRate
minimumPayment
```



### 1. principal

最初借入的本金。

例如：

```txt
信用卡最初欠款 35000 元
```



### 2. remainingPrincipal

当前仍未还清的本金。

例如已经偿还一部分后：

```txt
当前剩余 30000 元
```

本课模拟从“现在”开始，因此使用：

```txt
remainingPrincipal
```

而不是最初的 `principal`。

### 3. annualRate

年利率百分比。

例如：

```txt
"18"
```

表示：

```txt
18%
```



### 4. minimumPayment

每个月至少需要偿还的金额。

例如：

```txt
"1000.00"
```

当前数据库允许 `minimumPayment` 为空，但还款模拟必须知道最低还款额。

因此本课规定：

> 进入计算函数的每一笔债务都必须提供 `minimumPayment`。

数据库到计算函数之间的 service 或 API 以后需要拦截缺少最低还款额的数据。

计算函数不能自行猜测：

```txt
最低还款是余额的 5%？
还是固定 500 元？
是否包含利息？
```



## 三、最低还款和额外还款

假设有三笔债务：


| 债务   | 最低还款    |
| ---- | ------- |
| 学费借款 | 500 元   |
| 信用卡  | 1,000 元 |
| 消费贷  | 800 元   |


最低还款合计：

```txt
500 + 1000 + 800 = 2300
```

如果用户每月还能额外拿出：

```txt
1500
```

则固定月还款预算是：

```txt
2300 + 1500 = 3800
```

本课使用两个概念：

```txt
minimumPayment
  每笔债务必须先支付的最低还款

extraPayment
  支付完所有最低还款后，
  按策略集中偿还目标债务的额外金额
```



## 四、为什么要保持固定月还款预算

假设学费借款还清后，它原来的最低还款是：

```txt
500 元
```

如果用户下一月把总还款减少 500 元，其他债务不会加速偿还。

雪球法和雪崩法真正发挥作用的关键是：

> 一笔债务还清后，把它释放的最低还款继续投入下一笔债务。

因此本课在模拟开始时计算：

```txt
固定月还款预算
= 所有最低还款之和 + 每月额外还款
```

后续月份预算不降低。

这就是“滚动还款”：

```txt
债务 A 还清
  ↓
A 的最低还款被释放
  ↓
与原额外还款一起投入债务 B
```



## 五、债务雪球法

雪球法的规则是：

```txt
按当前模拟开始时的剩余本金从小到大排序
```

例如：


| 债务   | 剩余本金     | 年利率 |
| ---- | -------- | --- |
| 学费借款 | 10,000 元 | 5%  |
| 消费贷  | 20,000 元 | 10% |
| 信用卡  | 30,000 元 | 18% |


雪球法顺序：

```txt
学费借款
  ↓
消费贷
  ↓
信用卡
```

每个月：

1. 所有债务先计息。
2. 所有债务先支付最低还款。
3. 剩余预算优先投入学费借款。
4. 学费借款还清后转向消费贷。
5. 消费贷还清后转向信用卡。

雪球法的优势通常是：

- 更快消灭第一笔小债务。
- 更早看到债务数量减少。
- 心理反馈更明显。
- 有些人更容易坚持。

它的缺点是：

- 余额最小的债务不一定利率最高。
- 总利息可能高于雪崩法。



## 六、债务雪崩法

雪崩法的规则是：

```txt
按年利率从高到低排序
```

使用同一组债务：


| 债务   | 剩余本金     | 年利率 |
| ---- | -------- | --- |
| 学费借款 | 10,000 元 | 5%  |
| 消费贷  | 20,000 元 | 10% |
| 信用卡  | 30,000 元 | 18% |


雪崩法顺序：

```txt
信用卡
  ↓
消费贷
  ↓
学费借款
```

雪崩法的优势通常是：

- 优先减少利率最高的本金。
- 在其他条件相同时，总利息通常更低。
- 数学成本更优。

它的缺点是：

- 第一笔高息债务可能余额很大。
- 用户可能较长时间看不到债务数量减少。
- 心理反馈可能不如雪球法明显。



## 七、相同值时如何排序

只说“余额从小到大”还不够。

如果两笔债务余额完全相同，结果顺序可能不稳定。

本课规定完整排序规则。

### 雪球法

```txt
1. 剩余本金较小的优先
2. 本金相同时，年利率较高的优先
3. 仍相同时，按 id 字符串排序
```



### 雪崩法

```txt
1. 年利率较高的优先
2. 利率相同时，剩余本金较小的优先
3. 仍相同时，按 id 字符串排序
```

最后使用 `id` 不是财务策略，而是为了保证：

```txt
相同输入
  ↓
永远得到相同排序
```

这会让测试稳定，也便于以后追溯计算。

## 八、本课的月度计算顺序

真实贷款可能：

- 按日计息。
- 使用账单日和还款日。
- 有手续费。
- 有分段利率。
- 最低还款规则会随余额变化。

为了先建立可测试的计算引擎，本课采用明确的简化模型：

```txt
月初剩余本金
  ↓
按月利率计算当月利息
  ↓
利息加入债务余额
  ↓
支付每笔债务最低还款
  ↓
剩余固定预算按策略还款
  ↓
得到月末剩余余额
```

每个月统一：

> 先计息，后还款。

如果将来改成先还款后计息，结果会不同。

计算口径必须写清楚，不能让函数和页面各自理解。

## 九、把年利率转换为月利率

本课与第 23 课保持一致，使用名义年利率：

```txt
月利率 = 年利率 ÷ 100 ÷ 12
```

例如：

```txt
年利率 = 18%
```

计算：

```txt
18 ÷ 100 ÷ 12 = 0.015
```

也就是：

```txt
每月 1.5%
```

如果月初剩余本金为：

```txt
30000 元
```

当月利息：

```txt
30000 × 0.015 = 450 元
```



## 十、每个月的利息如何取整

利息最终会进入债务余额，因此它是金额。

本课规定：

```txt
每笔债务每个月的利息
  按四舍五入保留两位小数
```

对应：

```ts
Decimal.ROUND_HALF_UP
```

然后再把利息加入余额。

不要累计很多个月的高精度利息，最后才一次性保留两位。

原因是本课的业务规则明确模拟：

```txt
每月生成一笔以分为单位的利息
```

真实金融机构的利息舍入规则可能不同。

本课结果是基于本课口径的估算，不应冒充具体银行账单。

## 十一、还款不能超过剩余债务

假设某笔债务计息后只剩：

```txt
300 元
```

它的最低还款是：

```txt
500 元
```

实际支付应该是：

```txt
min(500, 300) = 300
```

不能支付 500 元后得到：

```txt
-200 元债务
```

额外还款也使用相同规则：

```txt
实际额外还款
= min(剩余可用预算, 当前债务余额)
```

多出来的预算继续投入优先级中的下一笔债务。

## 十二、为什么不能只写一个公式

储蓄目标可以使用一个复利终值公式直接得到结果。

多笔债务偿还不同。

每个月都会发生：

- 每笔债务产生不同利息。
- 每笔债务支付最低还款。
- 某笔债务可能在当月还清。
- 释放的预算可能继续支付下一笔。
- 下一月需要重新判断哪些债务仍然存在。

因此更适合使用：

```txt
逐月模拟
```

基本结构：

```ts
while (还有未还清债务) {
  月份加 1;
  计算当月利息;
  支付最低还款;
  按策略分配剩余预算;
}
```

## 十四、设计输出类型

继续定义：


字段含义：


| 字段                   | 含义            |
| -------------------- | ------------- |
| `strategy`           | 本次使用的策略       |

| `totalPrincipal`     | 模拟开始时的剩余本金合计  |

## 十五、建立内部计算状态

输入对象不应该在模拟过程中被修改。

因此建立内部类型：

```ts
type DebtState = {
  id: string;
  name: string;
  balance: Decimal;
  annualRate: Decimal;
  minimumPayment: Decimal;
  totalInterest: Decimal;
  totalPaid: Decimal;
  paidOffMonth: number | null;
};
```

计算开始时，把输入转换为一组新的 `DebtState`。

这样可以保证：

```txt
相同的 input
  ↓
先运行雪球法
  ↓
再运行雪崩法
```

第二次运行不会受到第一次修改余额的影响。

## 十六、编写金额取整辅助函数

```ts
function roundMoney(value: Decimal) {

```

`toMoneyString()` 用于最终输出字符串。

## 十七、校验输入

增加：

```ts
function assertDebtInput(input: DebtPayoffInput) {
  if (input.debts.length === 0) {
    throw new Error("至少需要一笔债务");
  }

  const ids = new Set<string>();

  for (const debt of input.debts) {
    if (debt.id.trim() === "") {
      throw new Error("债务 id 不能为空");
    }

    if (ids.has(debt.id)) {
      throw new Error(`债务 id 重复：${debt.id}`);
    }

    ids.add(debt.id);

    const balance = createMoney(debt.balance);
    const annualRate = new Decimal(debt.annualRate);
    const minimumPayment =
      createMoney(debt.minimumPayment);

    if (balance.lessThanOrEqualTo(0)) {
      throw new Error("债务余额必须大于 0");
    }

    if (!annualRate.isFinite() ||
        annualRate.isNegative()) {
      throw new Error("年利率必须是非负有限数字");
    }

    if (minimumPayment.lessThanOrEqualTo(0)) {
      throw new Error("最低还款额必须大于 0");
    }
  }

  const extraPayment = createMoney(
    input.extraPayment
  );

  if (extraPayment.isNegative()) {
    throw new Error("额外还款不能为负数");
  }
}
```

本课只模拟尚未还清的债务，因此要求：

```txt
balance > 0
```

余额已经是 `0` 的债务，应由调用方过滤掉，不要继续参与策略排序。

## 十八、实现稳定的策略排序

增加：

```ts
function sortDebts(
  debts: DebtState[],
  strategy: DebtPayoffStrategy
) {
  return [...debts].sort((left, right) => {
    if (strategy === "snowball") {
      const balanceOrder =
        left.balance.comparedTo(right.balance);

      if (balanceOrder !== 0) {
        return balanceOrder;
      }

      const rateOrder =
        right.annualRate.comparedTo(
          left.annualRate
        );

      if (rateOrder !== 0) {
        return rateOrder;
      }
    } else {
      const rateOrder =
        right.annualRate.comparedTo(
          left.annualRate
        );

      if (rateOrder !== 0) {
        return rateOrder;
      }

      const balanceOrder =
        left.balance.comparedTo(right.balance);

      if (balanceOrder !== 0) {
        return balanceOrder;
      }
    }

    return left.id.localeCompare(right.id);
  });
}
```

函数使用：

```ts
return [...debts].sort(...)
```

而不是直接：

```ts
debts.sort(...)
```

因为原地排序也是一种修改。

纯计算代码应尽量避免让调用方意外看到输入顺序变化。

## 十九、为什么优先顺序在模拟开始时固定

本课先执行一次：

```ts
const priorityOrder = sortDebts(
  states,
  input.strategy
).map((debt) => debt.id);
```

之后一直沿用这个顺序。

雪球法的含义是：

```txt
选定最小债务
  ↓
集中偿还直到它归零
  ↓
再转向下一笔
```

如果每个月都按照变化后的余额重新排序，额外还款可能在多笔债务之间反复跳转。

这不符合本课要实现的“集中还清一笔，再滚向下一笔”的策略。

## 二十、实现债务状态转换

在 `simulateDebtPayoff()` 中，校验后创建状态：

```ts
const states: DebtState[] = input.debts.map(

      debt.minimumPayment

```

计算总本金：

```ts
const totalPrincipal = states.reduce(
  (total, debt) => total.plus(debt.balance),
  createMoney("0")

```

计算固定月预算：

```ts
const minimumPaymentTotal = states.reduce(
  (total, debt) =>
    total.plus(debt.minimumPayment),
  createMoney("0")

const totalMonthlyBudget =
  minimumPaymentTotal.plus(
    createMoney(input.extraPayment)
  );
```



## 二十一、为无限循环设置保护边界

如果：

- 债务利率非常高。
- 最低还款非常低。
- 额外还款为 `0`。

每月还款可能长期无法覆盖利息。

这时：

```ts
while (还有债务)
```

可能永远不会结束。

因此本课设置：

```ts
const MAX_PAYOFF_MONTHS = 1200;
```

也就是最多模拟 100 年。

超过后抛出错误：

```txt
在 1200 个月内无法还清债务，请提高月还款预算
```

1200 不是理想还款期限，只是程序安全边界。

## 二十二、计算每月利息

每个月开始时：

```ts
for (const debt of states) {
  if (debt.balance.isZero()) {
    continue;
  }

  const monthlyRate = debt.annualRate
    .dividedBy(100)
    .dividedBy(12);

  const interest = roundMoney(
    debt.balance.times(monthlyRate)
  );

  debt.balance = debt.balance.plus(interest);
  debt.totalInterest =
    debt.totalInterest.plus(interest);
}
```

这里累计了两项：

```txt
balance
  当前还需要偿还的本金和已产生利息

totalInterest
  整个模拟过程中产生过的利息合计
```



## 二十三、先支付所有最低还款

当月利息生成后，先处理最低还款：

```ts
let paidThisMonth = createMoney("0");

for (const debt of states) {
  if (debt.balance.isZero()) {
    continue;
  }

  const payment = Decimal.min(
    debt.minimumPayment,
    debt.balance
  );

  debt.balance = debt.balance.minus(payment);
  debt.totalPaid = debt.totalPaid.plus(payment);
  paidThisMonth = paidThisMonth.plus(payment);

  if (debt.balance.isZero()) {
    debt.paidOffMonth = month;
  }
}
```

为什么最低还款要先支付给所有债务？

因为策略只决定：

```txt
额外预算优先投向哪里
```

它不表示可以停止支付其他债务的最低还款。

## 二十四、计算当月剩余预算

固定月预算减去已经支付的最低还款：

```ts
let remainingBudget =
  totalMonthlyBudget.minus(paidThisMonth);
```

如果某笔债务只剩 `300` 元，但最低还款是 `500` 元：

```txt
少用掉的 200 元
```

会留在 `remainingBudget` 中。

它可以在同一个月继续偿还下一笔债务，不会被浪费。

## 二十五、按策略投入剩余预算

按照固定的 `priorityOrder`：

```ts
for (const debtId of priorityOrder) {
  if (remainingBudget.isZero()) {
    break;
  }

  const debt = states.find(
    (item) => item.id === debtId
  );

  if (!debt || debt.balance.isZero()) {
    continue;
  }

  const payment = Decimal.min(
    remainingBudget,
    debt.balance
  );

  debt.balance = debt.balance.minus(payment);
  debt.totalPaid = debt.totalPaid.plus(payment);
  remainingBudget =
    remainingBudget.minus(payment);

  if (debt.balance.isZero()) {
    debt.paidOffMonth = month;
  }
}
```

如果第一优先债务在当月还清：

```txt
剩余预算 > 0
```

循环会立即继续偿还第二优先债务。

不需要等到下个月。

## 二十六、完整实现还款模拟

把前面的步骤组合起来：

```ts
const MAX_PAYOFF_MONTHS = 1200;

export function simulateDebtPayoff(
  input: DebtPayoffInput
): DebtPayoffResult {
  assertDebtInput(input);

  const states: DebtState[] = input.debts.map(
    (debt) => ({
      id: debt.id,
      name: debt.name,
      balance: createMoney(debt.balance),
      annualRate: new Decimal(debt.annualRate),
      minimumPayment: createMoney(
        debt.minimumPayment
      ),
      totalInterest: createMoney("0"),
      totalPaid: createMoney("0"),
      paidOffMonth: null
    })
  );

  const priorityOrder = sortDebts(
    states,
    input.strategy
  ).map((debt) => debt.id);

  const totalPrincipal = states.reduce(
    (total, debt) => total.plus(debt.balance),
    createMoney("0")
  );

  const minimumPaymentTotal = states.reduce(
    (total, debt) =>
      total.plus(debt.minimumPayment),
    createMoney("0")
  );

  const totalMonthlyBudget =
    minimumPaymentTotal.plus(
      createMoney(input.extraPayment)
    );

  let month = 0;

  while (states.some(
    (debt) => debt.balance.greaterThan(0)
  )) {
    month += 1;

    if (month > MAX_PAYOFF_MONTHS) {
      throw new Error(
        "在 1200 个月内无法还清债务，" +
        "请提高月还款预算"
      );
    }

    for (const debt of states) {
      if (debt.balance.isZero()) {
        continue;
      }

      const monthlyRate = debt.annualRate
        .dividedBy(100)
        .dividedBy(12);

      const interest = roundMoney(
        debt.balance.times(monthlyRate)
      );

      debt.balance =
        debt.balance.plus(interest);
      debt.totalInterest =
        debt.totalInterest.plus(interest);
    }

    let paidThisMonth = createMoney("0");

    for (const debt of states) {
      if (debt.balance.isZero()) {
        continue;
      }

      const payment = Decimal.min(
        debt.minimumPayment,
        debt.balance
      );

      debt.balance =
        debt.balance.minus(payment);
      debt.totalPaid =
        debt.totalPaid.plus(payment);
      paidThisMonth =
        paidThisMonth.plus(payment);

      if (debt.balance.isZero()) {
        debt.paidOffMonth = month;
      }
    }

    let remainingBudget =
      totalMonthlyBudget.minus(
        paidThisMonth
      );

    for (const debtId of priorityOrder) {
      if (remainingBudget.isZero()) {
        break;
      }

      const debt = states.find(
        (item) => item.id === debtId
      );

      if (!debt || debt.balance.isZero()) {
        continue;
      }

      const payment = Decimal.min(
        remainingBudget,
        debt.balance
      );

      debt.balance =
        debt.balance.minus(payment);
      debt.totalPaid =
        debt.totalPaid.plus(payment);
      remainingBudget =
        remainingBudget.minus(payment);

      if (debt.balance.isZero()) {
        debt.paidOffMonth = month;
      }
    }
  }

  const totalInterest = states.reduce(
    (total, debt) =>
      total.plus(debt.totalInterest),
    createMoney("0")
  );

  const totalPaid = states.reduce(
    (total, debt) => total.plus(debt.totalPaid),
    createMoney("0")
  );

  return {
    strategy: input.strategy,
    priorityOrder,
    totalPrincipal: toMoneyString(totalPrincipal),
    totalMonthlyBudget:
      toMoneyString(totalMonthlyBudget),
    payoffMonths: month,
    totalInterest: toMoneyString(totalInterest),
    totalPaid: toMoneyString(totalPaid),
    debts: states.map((debt) => ({
      id: debt.id,
      name: debt.name,
      paidOffMonth: debt.paidOffMonth!,
      totalInterest:
        toMoneyString(debt.totalInterest),
      totalPaid: toMoneyString(debt.totalPaid)
    }))
  };
}
```



## 二十七、为什么这里的非空断言可以接受

最终映射中使用了：

```ts
debt.paidOffMonth!
```

通常不应随意使用非空断言。

这里能够成立，是因为：

```txt
while 循环结束
  ↓
所有 debt.balance 都等于 0
  ↓
每笔债务归零时都设置了 paidOffMonth
```

如果你希望把约束写得更显式，也可以替换成：

```ts
if (debt.paidOffMonth === null) {
  throw new Error("债务还清月份缺失");
}
```

再构造结果。

显式检查更冗长，但错误信息更清楚。

## 二十八、验证本金、利息和总支付的关系

当所有债务完全还清时，应满足：

```txt
总支付金额
= 初始剩余本金 + 总利息
```

由于本课每月利息都先保留到分，三者最后也应精确到分。

可以增加内部保护：

```ts
const expectedTotalPaid =
  totalPrincipal.plus(totalInterest);

if (!totalPaid.equals(expectedTotalPaid)) {
  throw new Error("债务还款汇总不一致");
}
```

把这段检查放在 `return` 之前。

这是一条很有价值的财务不变量：

> 钱的来源和去向应该能够对上。

```txt
负数：雪球法更快
```



## 三十、实现策略比较函数

```ts
export function compareDebtPayoffStrategies(
  input: DebtPayoffComparisonInput
): DebtPayoffComparisonResult {
  const snowball = simulateDebtPayoff({
    ...input,
    strategy: "snowball"
  });

  const avalanche = simulateDebtPayoff({
    ...input,
    strategy: "avalanche"
  });

  const interestDifference = createMoney(
    snowball.totalInterest
  ).minus(avalanche.totalInterest);

  return {
    snowball,
    avalanche,
    interestDifference:
      toMoneyString(interestDifference),
    monthDifference:
      snowball.payoffMonths -
      avalanche.payoffMonths
  };
}
```

为什么可以使用同一个 `input` 连续模拟两次？

因为 `simulateDebtPayoff()` 会把输入映射成新的内部状态，不会修改原始 `debts`。

数据库返回：

因为 `minimumPayment` 在数据库中可能是：

## 四十三、真实世界限制

本课模拟不包含：

- 按日计息。
- 账单日和还款日差异。
- 逾期费用。
- 复利罚息。
- 信用卡新增消费。
- 提前还款手续费。
- 浮动利率。
- 最低还款比例动态变化。
- 税务影响。

因此结果应该表述为：

```txt
按照当前余额、固定年利率、固定最低还款和
每月额外还款 1500 元的假设，
预计 18 个月还清。
```

不要表述为：

```txt
你一定会在 18 个月后还清。
```

真实产品还应提醒用户：

> 如果贷款合同存在提前还款费用或特殊计息规则，应以合同和贷款机构账单为准。



## 四十四、为什么不能让 AI 直接选择策略

用户以后可能会问：

```txt
我应该先还信用卡还是学费借款？
```

AI 可以：

- 理解用户问题。
- 提取“比较债务策略”的意图。
- 解释雪球法和雪崩法的取舍。
- 根据确定性结果组织回复。

AI 不应该：

- 自己猜最低还款额。
- 在回复里随意计算复利利息。
- 忽略某笔债务。
- 不说明预算假设就宣布还清时间。

正确流程：

```txt
用户自然语言
  ↓
AI 解析 debt_payoff 意图
  ↓
Zod 校验
  ↓
读取 liabilities
  ↓
compareDebtPayoffStrategies()
  ↓
AI 解释两种策略的成本和取舍
```



## 四十五、常见错误



### 1. 雪球法和雪崩法使用不同预算

比较策略时必须保证：

```txt
债务相同
最低还款相同
额外还款相同
计息规则相同
```

否则差异不再只是策略造成的。

### 2. 只偿还目标债务

优先还款不代表停止支付其他债务的最低还款。

### 3. 债务还清后降低月预算

被释放的最低还款应该滚入下一笔债务，否则无法形成雪球或雪崩效果。

### 4. 每月重新切换雪球目标

本课在开始时固定优先顺序，一笔还清后才转向下一笔。

### 5. 还款超过剩余余额

所有还款都必须使用：

```txt
min(可用还款, 剩余余额)
```



### 6. 使用普通 number 计算金额

本金、利息、还款和余额都应该使用 `Decimal`。

### 7. 没有设置最大模拟月份

预算不足时循环可能永远无法结束。

### 8. 用最初本金参与模拟

从现在开始的策略应使用 `remainingPrincipal`，不是已经部分偿还前的 `principal`。

### 9. 把估算结果当成银行账单

真实合同的计息、舍入和费用规则可能不同。

## 四十九、复习问题



### 1. 雪球法和雪崩法分别按什么排序？

雪球法优先偿还余额较小的债务；雪崩法优先偿还年利率较高的债务。

### 2. 为什么其他债务仍要支付最低还款？

优先策略只决定额外预算的分配顺序，不代表可以停止履行其他债务的最低还款要求。

### 3. 什么是固定月还款预算？

它等于模拟开始时所有最低还款之和加每月额外还款。某笔债务还清后，总预算不降低，释放的金额继续偿还下一笔。

### 4. 为什么本课使用逐月模拟？

每月利息、最低还款、债务归零和额外预算分配都会改变下一月状态，无法用一个简单公式同时表达多笔债务的完整过程。

### 5. 为什么先计息再还款？

这是本课明确选择的简化计算口径。只有统一每月事件顺序，结果才可测试、可复算。

### 6. 为什么每月利息要保留两位小数？

本课把每月产生的利息视为一笔以分为单位的金额。真实贷款机构可能采用其他舍入规则。

### 7. 为什么还款要取预算和余额中的较小值？

这样可以防止最后一期多还并产生负债务余额，多余预算还可以继续偿还下一笔债务。

### 8. 为什么要设置 1200 个月上限？

当预算长期无法覆盖利息时，模拟可能永远不结束。上限是程序保护，不是合理还款建议。

### 9. 为什么策略比较必须使用相同预算？

只有债务、预算和计息规则都相同时，结果差异才能归因于偿还顺序。

### 10. 为什么雪崩法通常利息更低？

它更早减少高利率债务的本金，从而降低后续月份产生利息的基数。

### 11. 为什么有人仍会选择雪球法？

雪球法通常更早消灭小额债务，能提供明显的阶段反馈。有些用户更看重这种可坚持性。

### 12. 为什么本课结果只是估算？

真实贷款可能按日计息，还可能包含费用、浮动利率和动态最低还款。本课使用的是明确但简化的月度模型。

