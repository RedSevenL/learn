## 四、仪表盘最重要的是口径

同一个名称可能有不同含义。

例如“负债率”可能指：

```txt
总负债 ÷ 总资产
```

也可能指：

```txt
每月还债金额 ÷ 月收入
```

本课采用前者，并在界面显示说明：

```txt
资产负债率 = 当前总负债 ÷ 当前总资产
```

每个指标至少要明确：

- 计算公式。
- 使用哪些表。
- 使用哪个时间范围。
- 哪些数据被排除。
- 分母为 0 时怎么办。
- 没有数据时显示 0 还是空值。

没有口径的漂亮数字不值得信任。

## 五、本课的指标定义

### 1. 总资产

本课定义：

```txt
总资产
=
cash 账户余额
+
bank 账户余额
+
investment 账户余额
```

暂不计入：

- `credit` 账户。
- 房产估值。
- 车辆估值。
- 未建模的其他资产。
- 未来收入。

### 2. 总负债

本课定义：

```txt
总负债
=
所有未删除 liabilities.remainingPrincipal 之和
```

不使用最初借款金额：

```txt
principal
```

因为仪表盘需要展示当前剩余负债。

### 3. 净资产

```txt
净资产 = 总资产 - 总负债
```

净资产可以为负数。

### 4. 月收入

复用：

```txt
calculateMonthlyCashFlow(...).income
```

只统计所选基准月份的 `income` 流水。

### 5. 月支出

复用：

```txt
calculateMonthlyCashFlow(...).totalExpense
```

只统计所选基准月份的 `expense` 流水。

转账不算收入，也不算支出。

### 6. 储蓄率

复用第 22 课定义：

```txt
储蓄率
=
(月收入 - 月支出) ÷ 月收入 × 100%
```

月收入为 0 时：

```txt
savingsRate = null
```

界面显示：

```txt
—
```

而不是错误地显示 `0%`。

### 7. 资产负债率

```txt
资产负债率
=
总负债 ÷ 总资产 × 100%
```

当总资产小于或等于 0 时：

```txt
debtRatio = null
```

资产负债率可以超过 `100%`，不要强行限制到 100。

## 六、为什么信用卡账户暂不计入总资产

当前 `accounts.type` 包含：

```txt
cash
bank
credit
investment
```

但是当前模型没有明确规定信用卡 `balance` 表示：

- 已欠金额。
- 可用额度。
- 账户净余额。

如果直接把它加到资产中，可能把信用额度误当成资产。

本课选择：

```txt
credit 账户不计入资产
负债统一从 liabilities 读取
```

这是一个明确的课程口径，不代表所有财务产品都必须这样设计。

未来如果为信用卡建立专门模型，需要同步调整指标定义。

## 七、基准数据和筛选条件

本课有两类时间概念：

### 当前状态指标

这些使用查询时数据库中的最新状态：

```txt

总负债
净资产
```

### 月度流量指标

这些使用用户选中的基准月份：

```txt

月支出
月结余
储蓄率

```

### 趋势指标

这些使用：

```txt

```

```txt

```

```txt

2026-03
2026-04
2026-05
2026-06
2026-07
```

界面必须告诉用户：

```txt
资产类指标为当前快照
现金流指标按所选月份统计
```

```ts
const MONTH_PATTERN = /^\d{4}-(0[1-9]|1[0-2])$/;

function assertDashboardRange(
  baseMonth: string,
```

## 十二、生成连续月份

不要使用：

```ts
date.setMonth(date.getMonth() - 1);
```

再依赖本地时区隐式格式化。

月份本身可以使用整数算术：

```ts
export function listRecentMonths(
  baseMonth: string,
  count: number
) {
  if (!MONTH_PATTERN.test(baseMonth)) {
    throw new Error("月份格式必须是 YYYY-MM");
  }

  if (!Number.isInteger(count) || count <= 0) {
    throw new Error("月份数量必须是正整数");
  }

  const [baseYear, baseMonthNumber] =
    baseMonth.split("-").map(Number);
  const baseIndex = baseYear * 12 + baseMonthNumber - 1;

  return Array.from({ length: count }, (_, index) => {
    const monthIndex = baseIndex - count + 1 + index;
    const year = Math.floor(monthIndex / 12);
    const month = (monthIndex % 12) + 1;

    return `${year}-${String(month).padStart(2, "0")}`;
  });
}
```

测试：

```ts
expect(listRecentMonths("2026-07", 3)).toEqual([
  "2026-05",
  "2026-06",
  "2026-07"
]);

expect(listRecentMonths("2026-01", 3)).toEqual([
  "2025-11",
  "2025-12",
  "2026-01"
]);
```

跨年是最容易漏掉的边界。

## 十三、计算总资产

导入金额工具：

```ts

  divideMoney,
```

实现：

```ts
function calculateTotalAssets(
  accounts: DashboardAccount[]
) {
  let total = createMoney("0");

  for (const account of accounts) {
    if (account.currency !== "CNY") {
      throw new Error("当前仪表盘暂不支持多币种汇总");
    }

    if (
      account.type === "cash" ||
      account.type === "bank" ||
      account.type === "investment"
    ) {
      total = addMoney(total, account.balance);
    }
  }

  return total;
}
```

```ts
accounts.reduce(
  (sum, account) => sum + Number(account.balance),
  0
);
```

## 十四、计算总负债和净资产

```ts
function calculateTotalLiabilities(
  liabilities: DashboardLiability[]
) {
  let total = createMoney("0");

  for (const liability of liabilities) {
    total = addMoney(total, liability.remainingPrincipal);
  }

  return total;
}
```

然后：

```ts
const totalAssets = calculateTotalAssets(input.accounts);
const totalLiabilities = calculateTotalLiabilities(
  input.liabilities
);
const netWorth = subtractMoney(totalAssets, totalLiabilities);
```

如果负债超过资产：

```txt

```

这是合法结果，不要改成 0。

## 十八、按分类聚合支出

继续在：

```txt
lib/finance/dashboard.ts
```

实现：

```ts
function calculateCategoryExpenses(input: {
  baseMonth: string;
  transactions: DashboardTransaction[];
}): CategoryExpensePoint[] {
  const amountByCategory = new Map<string, Decimal>();
  let totalExpense = createMoney("0");

  for (const transaction of input.transactions) {
    if (
      transaction.direction !== "expense" ||
      toShanghaiMonth(transaction.occurredAt) !== input.baseMonth
    ) {
      continue;
    }

    const category = transaction.category?.trim() || "未分类";
    const amount = createMoney(transaction.amount);

    if (amount.isNegative()) {
      throw new Error("流水金额不能为负数");
    }

    amountByCategory.set(
      category,
      addMoney(
        amountByCategory.get(category) ?? "0",
        amount
      )
    );
    totalExpense = addMoney(totalExpense, amount);
  }

  return [...amountByCategory.entries()]
    .map(([category, amount]) => ({
      category,
      amount: toMoneyString(amount),
      share: totalExpense.isZero()
        ? "0.00"
        : divideMoney(amount, totalExpense)
            .times("100")
            .toFixed(2, Decimal.ROUND_HALF_UP)
    }))
    .sort((left, right) =>
      createMoney(right.amount)
        .comparedTo(createMoney(left.amount))
    );
}
```

这里：

- 只统计 `expense`。
- 排除 `income`。
- 排除 `transfer`。
- 空分类统一为“未分类”。
- 按金额从高到低排序。

## 十九、分类太多时怎么显示

分类超过 8 个时，全部放进图表会很拥挤。

可以在计算层继续保留完整分类结果，在图表层只显示：

```txt
前 7 个分类
  +
其他
```

但是“其他”金额也必须用 Decimal 汇总。

实现辅助函数：

```ts
export function groupSmallCategories(
  categories: CategoryExpensePoint[],
  visibleCount = 7
) {
  if (categories.length <= visibleCount) {
    return categories;
  }

  const visible = categories.slice(0, visibleCount);
  const otherAmount = categories
    .slice(visibleCount)
    .reduce(
      (total, item) => addMoney(total, item.amount),
      createMoney("0")
    );

  const fullTotal = categories.reduce(
    (total, item) => addMoney(total, item.amount),
    createMoney("0")
  );

  return [
    ...visible,
    {
      category: "其他",
      amount: toMoneyString(otherAmount),
      share: fullTotal.isZero()
        ? "0.00"
        : divideMoney(otherAmount, fullTotal)
            .times("100")
            .toFixed(2, Decimal.ROUND_HALF_UP)
    }
  ];
}
```

不要只截断而不告诉用户还有其他分类。

## 二十、完成仪表盘纯函数

```ts
export function calculateDashboard(
  input: DashboardInput
): DashboardResult {
  assertDashboardRange(input.baseMonth, input.trendMonths);

  const totalAssets = calculateTotalAssets(input.accounts);
  const totalLiabilities = calculateTotalLiabilities(
    input.liabilities
  );
  const netWorth = subtractMoney(totalAssets, totalLiabilities);

  const currentCashFlow = calculateMonthlyCashFlow({
    month: input.baseMonth,
    transactions: input.transactions,
    accounts: input.accounts
  });

  const debtRatio = totalAssets.lessThanOrEqualTo("0")
    ? null
    : divideMoney(totalLiabilities, totalAssets)
        .times("100")
        .toFixed(2, Decimal.ROUND_HALF_UP);

  const cashFlowTrend = listRecentMonths(
    input.baseMonth,
    input.trendMonths
  ).map((month) => {
    const cashFlow = calculateMonthlyCashFlow({
      month,
      transactions: input.transactions,
      accounts: input.accounts
    });

    return {
      month,
      income: cashFlow.income,
      expense: cashFlow.totalExpense,
      surplus: cashFlow.surplus,
      hasCashFlow: cashFlow.hasCashFlow
    };
  });

  const categoryExpenses = calculateCategoryExpenses({
    baseMonth: input.baseMonth,
    transactions: input.transactions
  });

  return {
    baseMonth: input.baseMonth,
    trendMonths: input.trendMonths,
    snapshotAt: Date.now(),
    hasFinancialData:
      input.accounts.length > 0 ||
      input.liabilities.length > 0 ||
      input.transactions.length > 0,
    metrics: {
      totalAssets: toMoneyString(totalAssets),
      totalLiabilities: toMoneyString(totalLiabilities),
      netWorth: toMoneyString(netWorth),
      monthlyIncome: currentCashFlow.income,
      monthlyExpense: currentCashFlow.totalExpense,
      monthlySurplus: currentCashFlow.surplus,
      savingsRate: currentCashFlow.savingsRate,
      debtRatio
    },
    cashFlowTrend,
    categoryExpenses
  };
}
```

`snapshotAt` 告诉客户端：

```txt
这些当前余额指标在什么时候生成
```

它不是历史资产快照。

## 二十四、建立仪表盘 API

创建：

```txt

```

写入：

```ts
import { errorResponse, successResponse } from "@/lib/api/response";
import { calculateDashboard } from "@/lib/finance/dashboard";
import { toShanghaiMonth } from "@/lib/finance/cash-flow";
import { listAccounts } from "@/lib/services/accounts";
import { listLiabilities } from "@/lib/services/liabilities";
import { listTransactions } from "@/lib/services/transactions";
import { dashboardQuerySchema } from "@/schemas/dashboard";
import { formatZodError } from "@/schemas/format-zod-error";

export async function GET(request: Request) {
  const url = new URL(request.url);
  const queryResult = dashboardQuerySchema.safeParse({
    month:
      url.searchParams.get("month") ??
      toShanghaiMonth(Date.now()),
    months: url.searchParams.get("months") ?? "6"
  });

  if (!queryResult.success) {
    return errorResponse(
      "VALIDATION_ERROR",
      "仪表盘筛选条件不合法",
      { status: 400 },
      {
        issues: formatZodError(queryResult.error)
      }
    );
  }

  try {
    const [accounts, transactions, liabilities] =
      await Promise.all([
        listAccounts(),
        listTransactions(),
        listLiabilities()
      ]);

    const unsupportedAccount = accounts.find(
      (account) => account.currency !== "CNY"
    );

    if (unsupportedAccount) {
      return errorResponse(
        "UNSUPPORTED_CURRENCY",
        "当前仪表盘暂不支持多币种汇总",
        { status: 422 }
      );
    }

    const dashboard = calculateDashboard({
      baseMonth: queryResult.data.month,
      trendMonths: queryResult.data.months,
      snapshotAt: Date.now(),
      accounts,
      transactions,
      liabilities
    });

    return successResponse({
      dashboard
    });
  } catch {
    return errorResponse(
      "DASHBOARD_ERROR",
      "仪表盘数据计算失败",
      { status: 500 }
    );
  }
}
```

这个 route 负责：

- 读取查询参数。
- 运行时校验。
- 并发读取三类数据。
- 调用纯函数。
- 映射稳定错误。

它不负责：

- JSX。
- 图表颜色。
- Tooltip 文案。
- 在 route 中手写财务公式。

## 二十五、为什么不让浏览器分别请求三个接口后计算

浏览器也可以请求：

```txt
/api/accounts
/api/transactions
/api/liabilities
```

再自己聚合。

但本课选择一个：

```txt
GET /api/dashboard
```

原因是：

- 指标口径集中在服务端计算层。
- 不必把所有原始流水发送到仪表盘页面。
- 页面只接收展示所需的聚合数据。
- 以后更容易增加缓存。
- 其他客户端可以复用相同结果。
- 测试边界更清楚。

页面是展示者，不是财务计算器。

```ts
import { formatMoney } from "@/lib/finance/money";

export function formatCompactMoney(value: number) {
  const absolute = Math.abs(value);
  const sign = value < 0 ? "-" : "";

  if (absolute >= 10000) {
    return `${sign}¥${(absolute / 10000).toFixed(1)}万`;
  }

  if (absolute >= 1000) {
    return `${sign}¥${(absolute / 1000).toFixed(1)}千`;
  }

  return `${sign}¥${absolute.toFixed(0)}`;
}

export function formatChartTooltipMoney(
  value: unknown
) {
  const scalarValue = Array.isArray(value) ? value[0] : value;
  return formatMoney(String(scalarValue ?? 0));
}
```

## 三十一、为什么父容器必须有高度

错误：

```tsx
<div>
  <ResponsiveContainer width="100%" height="100%">
```

父元素没有高度时，百分比高度可能计算为 0。

正确：

```tsx
<div className="h-80 min-w-0">
```

然后：

```tsx
<ResponsiveContainer width="100%" height="100%">
```

`min-w-0` 可以避免图表在 Grid 或 Flex 布局中撑破父容器。

## 三十二、为什么趋势图用折线图

折线图适合展示：

```txt
同一指标
沿连续时间变化
```

本课的横轴是连续月份，纵轴是金额，所以折线图合适。

分类支出不是时间序列，不应该也使用折线图。

图表类型应由数据关系决定，而不是由视觉偏好决定。

## 三十三、分类支出为什么使用条形图

分类名称可能较长：

```txt
居住
交通
医疗健康
学习与教育
```

横向条形图可以：

- 直接比较长度。
- 容纳较长分类名称。
- 保持从高到低排序。
- 比饼图更容易比较接近的金额。

本课不使用饼图。

“分类支出图”不等于必须使用饼图。

## 四十、取得上海当前月份

页面初始月份不能依赖：

```ts
new Date().toISOString().slice(0, 7)
```

因为 `toISOString()` 使用 UTC。

在上海时区月初附近，UTC 月份可能与本地月份不同。

复用一个不依赖服务端模块的客户端辅助函数：

```ts
function getCurrentShanghaiMonth() {
  const parts = new Intl.DateTimeFormat("en", {
    timeZone: "Asia/Shanghai",
    year: "numeric",
    month: "2-digit"
  }).formatToParts(new Date());

  const year = parts.find((part) => part.type === "year")?.value;
  const month = parts.find((part) => part.type === "month")?.value;

  if (!year || !month) {
    throw new Error("无法确定当前月份");
  }

  return `${year}-${month}`;
}
```

也可以把 `toShanghaiMonth` 移入一个浏览器和服务端都安全的日期工具文件后复用。

## 四十一、加载仪表盘数据

页面状态：

```ts
const [month, setMonth] = useState(getCurrentShanghaiMonth);
const [trendMonths, setTrendMonths] = useState(6);
const [dashboard, setDashboard] =
  useState<DashboardApiData | null>(null);
const [isDashboardLoading, setIsDashboardLoading] =
  useState(true);
const [dashboardError, setDashboardError] =
  useState<string | null>(null);
```

加载：

```ts
useEffect(() => {
  const controller = new AbortController();

  async function loadDashboard() {
    setIsDashboardLoading(true);
    setDashboardError(null);

    try {
      const params = new URLSearchParams({
        month,
        months: String(trendMonths)
      });
      const response = await fetch(
        `/api/dashboard?${params.toString()}`,
        {
          signal: controller.signal
        }
      );
      const body: unknown = await response.json();
      const result = dashboardResponseSchema.safeParse(body);

      if (!result.success) {
        throw new Error("仪表盘响应格式不正确");
      }

      if (!response.ok) {
        throw new Error("仪表盘请求失败");
      }

      setDashboard(result.data.data.dashboard);
    } catch (error) {
      if (
        error instanceof DOMException &&
        error.name === "AbortError"
      ) {
        return;
      }

      setDashboardError("仪表盘数据加载失败，请稍后重试。");
    } finally {
      if (!controller.signal.aborted) {
        setIsDashboardLoading(false);
      }
    }
  }

  void loadDashboard();

  return () => {
    controller.abort();
  };
}, [month, trendMonths]);
```

## 四十二、成功 schema 不能解析错误响应

上一段只定义了成功响应 schema。

如果服务端返回：

```json
{
  "ok": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "仪表盘筛选条件不合法"
  }
}
```

成功 schema 会失败。

更完整的方式是建立联合类型：

```ts
export const dashboardErrorResponseSchema = z.object({
  ok: z.literal(false),
  error: z.object({
    code: z.string(),
    message: z.string()
  })
});

export const dashboardApiResponseSchema = z.discriminatedUnion(
  "ok",
  [
    dashboardResponseSchema,
    dashboardErrorResponseSchema
  ]
);
```

页面改为：

```ts
const parsed = dashboardApiResponseSchema.safeParse(body);

if (!parsed.success) {
  throw new Error("仪表盘响应格式不正确");
}

if (!response.ok || !parsed.data.ok) {
  throw new Error(parsed.data.ok
    ? "仪表盘请求失败"
    : parsed.data.error.message);
}

setDashboard(parsed.data.data.dashboard);
```

本课最终实现应使用联合响应 schema。

## 四十三、为什么需要 AbortController

用户可能快速切换：

```txt
2026-05
  ↓
2026-06
  ↓
2026-07
```

如果最旧请求最后才返回，它可能覆盖最新选择。

effect 清理时：

```ts
controller.abort();
```

可以取消浏览器对旧请求结果的等待。

这不是数据库事务取消。

本课的仪表盘请求是 GET，只读且可安全中止客户端等待。





## 八十五、复习问题

### 1. 为什么仪表盘首先要定义指标口径？

因为相同名称可能有不同公式、时间范围和数据来源，没有口径就无法判断数字是否可信。

### 2. 本课总资产包含哪些账户？

包含现金、银行卡和投资账户，不包含语义尚未明确的信用卡账户。

### 3. 为什么总负债使用 remainingPrincipal？

它表示当前剩余本金，`principal` 只是初始借款金额。

### 4. 净资产可以是负数吗？

可以。负债超过资产时，负净资产是有效财务状态。

### 5. 为什么历史月份筛选不等于历史净资产？

当前数据库没有账户和负债余额历史快照，资产类指标只能表示查询时的当前状态。

### 6. 为什么月收入和月支出要复用 calculateMonthlyCashFlow？

这样仪表盘与已有现金流接口、Chat 计算保持同一口径，避免重复算法漂移。

### 7. 月收入为 0 时储蓄率为什么不是 0%？

储蓄率分母不存在，无法计算；`null` 比 0 更准确。

### 8. 资产负债率为什么可能超过 100%？

当总负债大于总资产时，比率自然会超过 100%。

### 9. 为什么趋势必须保留空月份？

时间轴需要连续，删除空月份会掩盖数据缺口并产生错误视觉距离。

### 10. 为什么图表边界可以把字符串转成 number？

这个数只用于 SVG 坐标和交互，不参与财务结果计算；可信结果仍来自 Decimal 计算后的字符串。

### 11. 为什么分类支出使用条形图而不是折线图？

分类不是连续时间序列，条形长度更适合比较离散类别金额。

### 12. 为什么本课选择横向条形图而不是饼图？

横向条形图更容易比较接近数值，也能容纳较长分类名称。

### 13. ResponsiveContainer 为什么需要父元素高度？

百分比高度需要可计算的父级尺寸，否则图表可能得到 0 高度。

### 14. 为什么不能只用颜色区分收入和支出？

色觉差异用户可能无法可靠区分，需要图例、名称、Tooltip 和文本摘要共同表达。

### 15. 为什么页面不直接请求全部流水后聚合？

聚合 API 能集中指标口径、减少敏感原始数据暴露，并让其他客户端复用相同结果。

### 16. 为什么需要 AbortController？

它可以防止较早筛选请求晚返回后覆盖最新选择。

### 17. 为什么账户变更后要重新请求服务端？

净资产和负债率属于计算结果，重新请求能保持单一计算口径，而不是把公式复制到页面。

### 18. 无数据应该显示 0 还是空状态？

金额聚合可以返回 0，但页面仍应解释没有来源数据；不可计算的比率使用 `null`，图表使用明确空状态。

### 19. 为什么分类占比相加可能不是恰好 100%？

每个占比分别四舍五入后可能产生少量显示误差，金额本身没有改变。

### 20. 图表能代替文本指标吗？

不能。图表用于帮助理解关系，核心数值、说明和空状态仍要以文本表达。
