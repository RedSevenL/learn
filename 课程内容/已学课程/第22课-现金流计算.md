## 二、什么是现金流

现金流关注一段时间内钱的流入和流出。

最基础的关系是：

```txt
月收入 - 月支出 = 月结余
```

例如：


| 项目    | 金额       |
| ----- | -------- |
| 工资收入  | 10,000 元 |
| 房租    | 3,000 元  |
| 餐饮和交通 | 2,000 元  |


计算：

```txt
月收入 = 10000
固定支出 = 3000
可变支出 = 2000
月总支出 = 3000 + 2000 = 5000
月结余 = 10000 - 5000 = 5000
```

这些指标回答的是：

- 本月一共赚了多少？
- 必须支付的固定成本是多少？
- 日常消费是多少？
- 最终剩下多少钱？
- 目前的储蓄能力如何？



## 三、收入、支出和转账

当前流水方向有三种：

```ts
"income"
"expense"
"transfer"
```



### 1. income

表示外部资金流入：

- 工资。
- 副业。
- 奖金。
- 退款。
- 利息收入。

它会增加月收入。

### 2. expense

表示资金流出：

- 房租。
- 餐饮。
- 交通。
- 购物。
- 水电燃气。

它会增加月支出。

### 3. transfer

表示自己的账户之间转移资金：

```txt
工资卡 → 支付宝
银行卡 → 投资账户
银行卡 → 现金
```

转账不是收入，也不是支出。

如果把转账算成支出，银行卡转出时会增加支出；转入另一个账户时又可能增加收入，同一笔钱就被重复计算。

因此本课规则是：

> `transfer` 保留在流水记录中，但不计入现金流收入和支出。



## 四、金额正负号的统一规则

项目同时有：

```txt
amount
direction
```

如果 `direction` 已经表示收入或支出，`amount` 就不应该再依赖正负号表达方向。

本课统一规则：

```txt
amount 永远是非负金额
direction 决定收入、支出或转账
```

正确：

```ts
{
  amount: "3000.00",
  direction: "expense"
}
```

不要写：

```ts
{
  amount: "-3000.00",
  direction: "expense"
}
```

否则计算函数还要猜：

```txt
负支出是退款？
还是数据录入错误？
还是要再取绝对值？
```

## 五、固定支出和可变支出

支出可以继续分成两类。

### 固定支出

每月相对稳定、难以立即取消：

- 居住。
- 水电燃气。
- 通讯。
- 保险。
- 订阅。
- 最低还款。



### 可变支出

随生活选择变化：

- 餐饮。
- 交通。
- 购物。
- 娱乐。
- 旅行。

当前数据库只有：

```txt
category
```

还没有单独的：

```txt
expenseType
```

本课先通过分类名称判断。

建立项目约定：

```ts
const FIXED_EXPENSE_CATEGORIES = new Set([
  "居住",
  "水电燃气",
  "通讯",
  "保险",
  "订阅",
  "最低还款"
]);
```

命中这些分类的是固定支出，其余支出暂时归为可变支出。

这不是永远不变的财务标准。

后续可以：

- 增加分类设置页面。
- 让用户修改分类属性。
- 新增独立分类表。

## 六、储蓄率

储蓄率用于观察收入中有多少比例最终保留下来。

公式：

```txt
储蓄率 = 月结余 ÷ 月收入 × 100%
```

例如：

```txt
月收入 = 10000
月结余 = 5000
```

计算：

```txt
5000 ÷ 10000 × 100% = 50%
```

如果支出超过收入：

```txt
月收入 = 3000
月支出 = 4500
月结余 = -1500
```

储蓄率：

```txt
-1500 ÷ 3000 × 100% = -50%
```

负储蓄率是合法结果，表示本月发生超支。

### 收入为 0

如果月收入为 `0`：

```txt
结余 ÷ 0
```

没有可用结果。

本课规定：

```txt
收入为 0 时，savingsRate 返回 null
```

页面展示：

```txt
—
```

不要伪造：

```txt
0%
```

`0%` 意味着已经完成一次有效比率计算，而 `null` 表示当前无法计算。

## 七、安全现金月数

安全现金月数表示：

> 当前流动资金可以覆盖多少个月的当前支出。

本课使用：

```txt
安全现金月数 = 流动资产 ÷ 当月总支出
```

流动资产先按保守范围计算：

```txt
现金账户 cash
银行卡账户 bank
```

暂时不包含：

- `credit`：信用卡是负债工具。
- `investment`：投资资产可能有价格波动，也不一定能立即使用。

例如：

```txt
现金和银行卡余额 = 30000
月总支出 = 5000
```

安全现金月数：

```txt
30000 ÷ 5000 = 6.0 个月
```

如果当月支出为 `0`，分母为 `0`，本课返回：

```txt
null
```

页面展示：

```txt
—
```



## 八、月份和时区规则

项目工作时区是：

```txt
亚洲/上海 UTC+8
```

流水时间 `occurredAt` 保存为时间戳。

同一个时间戳在不同时区可能属于不同日期，甚至不同月份。

因此本课统一：

```txt
按亚洲/上海月份汇总
月份字符串使用 YYYY-MM
```

例如：

```txt
2026-07
```

计算函数不能偷偷读取当前时间。

当前月份应该在 API 边缘通过 `Date.now()` 得到，再作为参数传入纯函数。

## 十一、把时间戳转换为上海月份

在 `cash-flow.ts` 中增加：

```ts
const SHANGHAI_OFFSET_MS = 8 * 60 * 60 * 1000;

export function toShanghaiMonth(timestamp: number): string {
  const date = new Date(timestamp + SHANGHAI_OFFSET_MS);
  const year = date.getUTCFullYear();
  const month = String(date.getUTCMonth() + 1).padStart(
    2,
    "0"
  );

  return `${year}-${month}`;
}
```

这里先加八小时，再使用 UTC 字段读取。

这样得到的是 UTC+8 对应的年月。

测试时只要输入相同时间戳，就一定得到相同月份。

## 十四、编写现金流汇总函数

从 `money.ts` 导入：

```ts
import Decimal from "decimal.js";
import {
  addMoney,
  createMoney,
  divideMoney,
  subtractMoney,
  toMoneyString
} from "./money";
```

然后实现：

```ts
export function calculateMonthlyCashFlow(
  input: MonthlyCashFlowInput
): MonthlyCashFlowResult {
  assertMonth(input.month);

  let income = createMoney("0");
  let fixedExpense = createMoney("0");
  let variableExpense = createMoney("0");
  let cashFlowCount = 0;

  for (const transaction of input.transactions) {
    if (toShanghaiMonth(transaction.occurredAt) !== input.month) {
      continue;
    }

    const amount = createMoney(transaction.amount);

    if (amount.isNegative()) {
      throw new Error("流水金额不能为负数");
    }

    if (transaction.direction === "transfer") {
      continue;
    }

    if (transaction.direction === "income") {
      income = addMoney(income, amount);
      cashFlowCount += 1;
      continue;
    }

    if (transaction.direction === "expense") {
      if (isFixedExpense(transaction.category)) {
        fixedExpense = addMoney(fixedExpense, amount);
      } else {
        variableExpense = addMoney(variableExpense, amount);
      }

      cashFlowCount += 1;
      continue;
    }

    throw new Error(
      `未知流水方向：${transaction.direction}`
    );
  }

  const totalExpense = addMoney(
    fixedExpense,
    variableExpense
  );
  const surplus = subtractMoney(income, totalExpense);

  const savingsRate = income.isZero()
    ? null
    : divideMoney(surplus, income)
        .times("100")
        .toFixed(2, Decimal.ROUND_HALF_UP);

  let liquidAssets = createMoney("0");

  for (const account of input.accounts) {
    if (account.type === "cash" || account.type === "bank") {
      liquidAssets = addMoney(
        liquidAssets,
        account.balance
      );
    }
  }

  const safeCashMonths = totalExpense.isZero()
    ? null
    : liquidAssets.lessThanOrEqualTo("0")
      ? "0.0"
      : divideMoney(liquidAssets, totalExpense)
          .toFixed(1, Decimal.ROUND_HALF_UP);

  return {
    month: input.month,
    hasCashFlow: cashFlowCount > 0,
    income: toMoneyString(income),
    fixedExpense: toMoneyString(fixedExpense),
    variableExpense: toMoneyString(variableExpense),
    totalExpense: toMoneyString(totalExpense),
    surplus: toMoneyString(surplus),
    savingsRate,
    liquidAssets: toMoneyString(liquidAssets),
    safeCashMonths
  };
}
```



## 十五、理解汇总过程

函数按以下顺序工作：

```txt
校验月份
  ↓
只保留目标月份流水
  ↓
拒绝负 amount
  ↓
忽略 transfer
  ↓
累计 income
  ↓
按 category 拆分 fixed / variable
  ↓
计算 totalExpense
  ↓
计算 surplus
  ↓
计算 savingsRate
  ↓
汇总 cash / bank 余额
  ↓
计算 safeCashMonths
  ↓
统一输出字符串
```

它没有：

- 查询数据库。
- 调用 API。
- 读取当前时间。
- 修改 React state。

因此仍然是可测试的纯函数。

```ts
  const month =
    url.searchParams.get("month") ??
    toShanghaiMonth(Date.now());

  if (!/^\d{4}-(0[1-9]|1[0-2])$/.test(month)) {
    return errorResponse(
      "VALIDATION_ERROR",
      "月份格式必须是 YYYY-MM",
      { status: 400 }
    );
  }

  try {
    const [transactions, accounts] = await Promise.all([
      listTransactions(),
      listAccounts()
    ]);

    const cashFlow = calculateMonthlyCashFlow({
      month,
      transactions,
      accounts
    });

    return successResponse({
      cashFlow
    });
  } catch {
    return errorResponse(
      "CASH_FLOW_ERROR",
      "现金流计算失败",
      { status: 500 }
    );
  }
}
```

这里使用 `Promise.all()` 并行读取账户和流水。

两次查询互不依赖，不需要先后等待。

错误状态也要区分：

```txt
月份格式不正确
  → 400 VALIDATION_ERROR

数据库读取或内部计算失败
  → 500 CASH_FLOW_ERROR
```

该 GET Route Handler 会读取数据库和请求 URL，因此按当前 Next.js 16 行为在请求时执行，不需要额外设置静态缓存。

## 三十五、复习问题



### 1. 为什么转账不能算收入或支出？

转账只是自己的账户之间移动资金，没有改变整体财富。如果计入现金流，会重复统计同一笔钱。

### 2. 为什么 amount 要保持非负？

方向已经由 `direction` 表示。金额再使用正负号表达方向会产生两套规则，让计算函数无法判断负支出的真实含义。

### 3. 固定支出和可变支出如何区分？

本课根据 `category` 与固定分类集合进行映射。命中“居住、保险、订阅”等分类的是固定支出，其余支出暂时归为可变支出。

### 4. 为什么收入为 0 时储蓄率是 null？

储蓄率需要除以收入。收入为 0 时无法得到有意义的百分比，`null` 比伪造 `0%` 更准确。

### 5. 安全现金月数是什么？

它表示流动资产可以覆盖多少个月的当前支出。本课用现金与银行卡余额除以当月总支出。

### 6. 为什么投资账户不计入流动资产？

投资资产可能波动或无法立即使用。本课采用保守口径，只统计现金和银行卡。

### 7. 为什么计算函数不直接读取当前月份？

当前时间属于外部状态。把月份作为输入，函数才能在相同输入下稳定返回相同结果，也更容易测试历史月份。

### 8. 为什么页面不直接 reduce 流水？

页面应该负责展示和交互。把分类、Decimal 运算、比率和边界规则放进页面，会破坏计算层与 UI 层的边界。

### 9. 没有流水是错误吗？

不是。它是正常业务状态。API 返回零值和 `hasCashFlow: false`，页面据此显示引导性空状态。

### 10. 本课与第 23 课如何衔接？

第 23 课的储蓄目标需要当前金额、每月可储蓄金额和期限。本课得到的月结余可以成为“每月储蓄”的可靠输入。
