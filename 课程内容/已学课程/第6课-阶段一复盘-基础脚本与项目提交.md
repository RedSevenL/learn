## 四、定义流水类型

先定义流水类型。

```ts
type TransactionType = "income" | "expense";

type Transaction = {
  id: string;
  title: string;
  amount: number;
  type: TransactionType;
  category: string;
};
```

这里最重要的是：

```ts
type TransactionType = "income" | "expense";
```

它限制流水类型只能是收入或支出。

这样可以避免写出：

```ts
type: "cost"
```

这种不统一的数据。

## 六、定义返回结果类型

财务摘要应该有清晰的返回结构。

```ts
type CashflowSummary = {
  totalIncome: number;
  totalExpense: number;
  surplus: number;
  savingsRate: number;
  message: string;
};
```

字段含义：

| 字段 | 含义 |
| --- | --- |
| `totalIncome` | 总收入 |
| `totalExpense` | 总支出 |
| `surplus` | 结余 |
| `savingsRate` | 储蓄率 |
| `message` | 给用户看的提示文案 |

## 七、编写计算函数

现在写核心函数：

```ts
function calculateCashflowSummary(
  transactions: Transaction[]
): CashflowSummary {
  let totalIncome = 0;
  let totalExpense = 0;

  for (const transaction of transactions) {
    if (transaction.type === "income") {
      totalIncome = totalIncome + transaction.amount;
    }

    if (transaction.type === "expense") {
      totalExpense = totalExpense + transaction.amount;
    }
  }

  const surplus = totalIncome - totalExpense;
  const savingsRate = totalIncome === 0 ? 0 : surplus / totalIncome;

  let message = "";

  if (surplus > 0) {
    message = `本月结余 ${surplus} 元`;
  } else if (surplus === 0) {
    message = "本月收支平衡";
  } else {
    message = `本月超支 ${Math.abs(surplus)} 元`;
  }

  return {
    totalIncome,
    totalExpense,
    surplus,
    savingsRate,
    message
  };
}
```

这个函数有几个关键点：

- 输入是 `Transaction[]`。
- 输出是 `CashflowSummary`。
- 函数内部不读取文件、不操作数据库、不调用 API。
- 同样的输入，每次都会得到同样的输出。

这种函数叫纯函数。

后面财务计算引擎会大量使用这种写法。

## 八、格式化百分比

储蓄率是一个小数。

例如：

```txt
0.7342857142857143
```

用户不应该直接看到这种数字。

可以写一个简单格式化函数：

```ts
function formatPercent(value: number): string {
  return `${(value * 100).toFixed(2)}%`;
}
```

使用：

```ts
console.log(formatPercent(0.7342857142857143));
```

输出：

```txt
73.43%
```
