# ai-finance-cfo 项目结构说明

## 一、这个文件夹是什么

`ai-finance-cfo/` 是通过 `create-next-app` 创建出来的 Next.js 项目。

它不是普通空文件夹，而是一个已经具备基础运行能力的前端项目。当前可以通过下面命令启动：

```bash
cd ai-finance-cfo
npm run dev
```

启动后访问：

```txt
http://localhost:3000
```

## 二、最重要的目录

### `app/`

`app/` 是 Next.js App Router 的页面目录。

目前里面主要有：

```txt
app/
├── favicon.ico
├── globals.css
├── layout.tsx
└── page.tsx
```

### `app/page.tsx`

这是首页文件。

当前浏览器打开 `http://localhost:3000` 时，看到的默认 Next.js 页面主要就是由这个文件生成的。

后面学习 React 组件时，最先要改的通常就是它。

可以先把它理解为：

```txt
首页组件
```

### `app/layout.tsx`

这是整个应用的根布局。

它负责包住所有页面，通常放：

- HTML 语言设置。
- 全局字体。
- 全局页面结构。
- 页面元信息。

当前里面的 `metadata` 控制默认网页标题和描述：

```ts
export const metadata: Metadata = {
  title: "Create Next App",
  description: "Generated by create next app",
};
```

以后可以改成 AI 个人财务 CFO 相关内容。

### `app/globals.css`

这是全局 CSS 文件。

它会影响整个应用的样式。

当前主要做了几件事：

- 引入 Tailwind CSS。
- 设置背景色和前景色变量。
- 支持系统深色模式。
- 设置默认字体。

### `app/favicon.ico`

这是浏览器标签页左侧的小图标。

以后可以替换成自己的应用图标。

## 三、项目配置文件

### `package.json`

这是 npm 项目的核心配置文件。

它记录了：

- 项目名称。
- 项目版本。
- 常用命令。
- 生产依赖。
- 开发依赖。

当前常用命令是：

```json
{
  "dev": "next dev",
  "build": "next build",
  "start": "next start",
  "lint": "eslint"
}
```

含义：

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 启动开发服务器 |
| `npm run build` | 构建生产版本 |
| `npm run start` | 启动生产版本 |
| `npm run lint` | 检查代码规范 |

### `package-lock.json`

这是依赖锁定文件。

它记录每个依赖包的精确版本，保证以后重新安装依赖时结果尽量一致。

这个文件通常需要提交到 Git。

### `tsconfig.json`

这是 TypeScript 配置文件。

它告诉 TypeScript：

- 使用哪些语法规则。
- 如何处理 JSX。
- 是否开启严格类型检查。
- 哪些文件需要参与类型检查。
- 路径别名如何解析。

当前有一个重要配置：

```json
"strict": true
```

表示 TypeScript 会用比较严格的方式检查代码。

### `next.config.ts`

这是 Next.js 配置文件。

当前基本是空配置：

```ts
const nextConfig: NextConfig = {
  /* config options here */
};
```

说明暂时没有特殊 Next.js 配置。

### `eslint.config.mjs`

这是 ESLint 配置文件。

ESLint 用来检查代码质量和常见错误。

当前配置来自 Next.js 官方默认模板，包含：

- Next.js 推荐规则。
- TypeScript 规则。
- 忽略 `.next/`、`build/` 等构建产物。

### `postcss.config.mjs`

这是 PostCSS 配置文件。

当前主要用于接入 Tailwind CSS：

```js
plugins: {
  "@tailwindcss/postcss": {},
}
```

初学阶段一般不用改它。

### `next-env.d.ts`

这是 Next.js 自动生成的 TypeScript 类型声明文件。

它让 TypeScript 能识别 Next.js 的特殊类型。

这个文件不要手动编辑。

## 四、AI 辅助说明文件

### `AGENTS.md`

这是给 AI 编程助手看的项目说明文件。

新版 `create-next-app` 会自动生成它，用来提醒 AI：

- 当前 Next.js 版本可能有新规则。
- 写代码前应参考当前项目里的 Next.js 文档。

它不影响项目运行。

### `CLAUDE.md`

这是给 Claude Code 这类 AI 工具看的说明文件。

它也不影响项目运行。

如果不用 Claude，也可以暂时不用管它。

## 五、静态资源目录

### `public/`

`public/` 用来放可以被浏览器直接访问的静态文件。

当前里面有：

```txt
public/
├── file.svg
├── globe.svg
├── next.svg
├── vercel.svg
└── window.svg
```

这些都是 Next.js 默认首页使用的图标。

例如：

```txt
public/next.svg
```

在页面里可以通过下面路径访问：

```txt
/next.svg
```

以后项目自己的图片、图标、示例文件，也可以放在 `public/`。

## 六、本地生成目录

### `node_modules/`

这是依赖安装目录。

运行 `npm install` 或创建项目时，会把依赖包下载到这里。

特点：

- 文件非常多。
- 不需要手动修改。
- 不提交到 Git。
- 删除后可以通过 `npm install` 重新生成。

### `.next/`

这是 Next.js 运行或构建时生成的目录。

运行 `npm run dev` 后会出现。

特点：

- 存放编译缓存和运行产物。
- 不需要手动修改。
- 不提交到 Git。
- 删除后再次启动项目会自动生成。

## 七、当前最需要关注的文件

初学阶段不需要同时理解所有文件。

当前最重要的是这几个：

| 文件 | 当前学习重点 |
| --- | --- |
| `app/page.tsx` | 首页内容，练习 React 组件 |
| `app/layout.tsx` | 全局页面外壳和网页信息 |
| `app/globals.css` | 全局样式 |
| `package.json` | 项目命令和依赖 |

其他配置文件先知道用途即可，不需要马上深入。

## 八、推荐理解顺序

建议按这个顺序看：

1. 先看 `package.json`，理解 `npm run dev` 为什么能启动项目。
2. 再看 `app/page.tsx`，理解浏览器首页从哪里来。
3. 再看 `app/layout.tsx`，理解页面外面还有一层全局布局。
4. 再看 `app/globals.css`，理解页面样式从哪里来。
5. 最后再了解 `tsconfig.json`、`next.config.ts`、`eslint.config.mjs` 等配置文件。

## 九、简单总结

当前 `ai-finance-cfo/` 可以理解成：

```txt
ai-finance-cfo/
├── app/                  # 写页面和样式的核心目录
├── public/               # 静态资源
├── package.json          # 项目命令和依赖
├── package-lock.json     # 依赖版本锁定
├── tsconfig.json         # TypeScript 配置
├── next.config.ts        # Next.js 配置
├── eslint.config.mjs     # 代码检查配置
├── postcss.config.mjs    # CSS 工具配置
├── AGENTS.md             # AI 编程助手说明
├── CLAUDE.md             # Claude 工具说明
├── node_modules/         # 本地依赖，不提交
└── .next/                # 运行缓存，不提交
```

现在真正要动手改的，主要是：

```txt
app/page.tsx
```

也就是课程第 7 课里提到的首页组件。
