### props 流程

```
用户输入 "你好"
     ↓
textarea onChange
     ↓
event.target.value === "你好"
     ↓
onQuestionChange("你好")
     ↓
实际上执行父组件传进来的函数
     ↓
setQuestion("你好")
     ↓
父组件 question 变成 "你好"
     ↓
React 重新渲染
     ↓
question="你好" 再次传给 ChatComposer
     ↓
textarea 显示 "你好"
```

```
父组件 ChatPage

useState("")
   ↓
产生
question
setQuestion
   ↓

<ChatComposer
  question={question}
  onQuestionChange={(value) => setQuestion(value)}
/>

   ↓ Props 传进去

子组件 ChatComposer

type ChatComposerProps = {
  question: string;
  onQuestionChange: (value: string) => void;
};

   ↓

拿到：
question
onQuestionChange

   ↓

<textarea
  value={question}
  onChange={(event) =>
    onQuestionChange(event.target.value)
  }
/>
```
