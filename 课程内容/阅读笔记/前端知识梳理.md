### 关于类和对象

类是模板，对象是实例，可以创建类再 new，也可以直接创建对象，另外 type 是对象类型

对象数组 Account[]

读取对象属性 account.name;

构造函数 new 用来创建类的新实例对象

### 箭头函数

const double = (n) => n * 2;

带返回值的箭头函数，函数体为单行不加 {} 则自动补上 return

如果多行必须加 {} 并补上 return，如果单行加了 {} 也要补上 return

如果没返回值则无需 return，一般为调用函数去执行什么

const handleChange = (value: string) => {

  setName(value);

};

### extend

表示继承，是动作  
class MyError extends Error {

}

表示判断，判断两个类的类型是否相同，产生 true 或 false  
T extends U ? X : Y

### instanceof

用来判断，一个实例是否由一个类或该类的子类创建出来，产生的结果是 true 或 false
